# tripadvisor-clone
A TripAdvisor-inspired travel website built using HTML and CSS. It includes a sticky navigation bar, travel search section, popular destinations, hotel recommendations, Things to Do section, image zoom animations, Travelers’ Choice Awards, and a detailed footer. Created as a frontend development practice project.

## Features

- Sticky navigation bar
- "Where to?" hero section with search options
- Things to Do promotional section
- Popular destinations
- Top destinations for your next trip
- Best hotel recommendations
- Travelers' Choice Awards section
- Image zoom animations
- Responsive layout
- Detailed footer section

## Technologies Used

- HTML5
- CSS3

## Project Structure

TripAdvisor/
├── index.html
├── style.css
└── images/

## About the Project

This project was created as a frontend development practice project. It focuses on building a travel website interface using only HTML and CSS, including sections, cards, images, navigation, animations, and responsive styling.

All images used in the project are stored locally inside the `images` folder.

## Purpose

The main purpose of this project is to improve my frontend development skills and understand how to structure and style a real-world travel website using HTML and CSS.

## Disclaimer

This is a personal learning project inspired by the design and layout of TripAdvisor. It is not affiliated with or endorsed by TripAdvisor.
